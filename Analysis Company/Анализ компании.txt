
Добрый день!

Ты специалист экспертного уровня по исследованию и анализу деятельности компаний и организаций.
Подготовь максимально подробный аналитический обзор компании:

Название компании: «Название компании»
Официальный сайт: «Адрес сайта»

При подготовке обзора используй все доступные открытые источники информации:

* официальный сайт компании;
* вакансии компании;
* государственные реестры и базы данных;
* отраслевые публикации;
* деловые СМИ;
* профессиональные сообщества;
* отзывы клиентов;
* отзывы сотрудников;
* социальные сети компании;
* иные доступные достоверные источники.

Требования к достоверности:

1. Используй только подтвержденную информацию.
2. Если информация противоречива — укажи это отдельно.
3. Не выдумывай факты.
4. Если какие-либо сведения отсутствуют в открытом доступе — прямо сообщи об этом.
5. Отделяй факты от аналитических выводов.
6. Для ключевых утверждений указывай источник информации.
7. Используй максимально актуальные данные на момент выполнения запроса.

Структура отчета:

# 1. Общая информация

* история компании;
* сфера деятельности;
* основные направления бизнеса;
* география присутствия;
* численность персонала (если доступно);
* руководители и собственники (если доступны сведения).

# 2. Продукты и услуги

* основные продукты;
* ключевые направления деятельности;
* конкурентные преимущества;
* целевая аудитория.

# 3. Положение на рынке

* основные конкуренты;
* рыночная ниша;
* сильные стороны компании;
* слабые стороны компании;
* SWOT-анализ на основе доступных данных.

# 4. Маркетинговая стратегия

Если официальная маркетинговая стратегия не опубликована, 
выполни аналитическую реконструкцию стратегии по косвенным признакам:

* позиционирование бренда;
* уникальное торговое предложение;
* целевая аудитория;
* каналы привлечения клиентов;
* SEO;
* контент-маркетинг;
* социальные сети;
* контекстная реклама;
* партнерские программы;
* репутационный маркетинг;
* программы лояльности;
* PR-активность.

Для каждого вывода указывай, на каких фактах он основан.

# 5. Анализ цифрового присутствия

* качество официального сайта;
* социальные сети;
* активность публикаций;
* работа с отзывами;
* онлайн-репутация.

# 6. Финансовые и юридические аспекты

Если информация доступна:

* финансовые показатели;
* судебные дела;
* арбитражные споры;
* исполнительные производства;
* лицензии;
* сертификаты;
* признаки финансовых рисков.

# 7. Анализ компании как работодателя

Отдельно оцени:

* открытые вакансии;
* востребованные специалисты;
* требования к кандидатам;
* уровень заработной платы;
* перспективы карьерного роста;
* корпоративную культуру;
* систему мотивации;
* обучение сотрудников;
* отзывы работников;
* основные преимущества работы в компании;
* возможные риски для соискателей.

# 8. Итоговая оценка

Сделай итоговое заключение по следующим направлениям:

* надежность компании;
* рыночные перспективы;
* привлекательность для клиентов;
* привлекательность для партнеров;
* привлекательность для потенциальных сотрудников.

Для каждого вывода укажи степень уверенности:

Высокая / Средняя / Низкая.

Перед выводом результата выполни повторную проверку отчета на наличие неподтвержденных утверждений, 
логических противоречий и возможных галлюцинаций.
